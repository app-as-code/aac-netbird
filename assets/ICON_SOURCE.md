# Icon source

Icons are downloaded from the selfh.st icon collection (repository `selfhst/icons`,
served via jsdelivr), which provides ready-made logos for self-hosted applications.
No icon was drawn or modified by hand.

| File in this repo | Upstream file | Used for |
|---|---|---|
| `icon.svg` | `svg/netbird.svg` | Default (light mode) |
| `icon-light.svg` | `svg/netbird-dark.svg` | Dark-colored logo for light backgrounds |
| `icon-dark.svg` | `svg/netbird-light.svg` | Light-colored logo for dark mode |

Download URLs:

- https://cdn.jsdelivr.net/gh/selfhst/icons/svg/netbird.svg
- https://cdn.jsdelivr.net/gh/selfhst/icons/svg/netbird-dark.svg
- https://cdn.jsdelivr.net/gh/selfhst/icons/svg/netbird-light.svg
